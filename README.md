An AI-powered assistive system that helps visually impaired people understand their surroundings independently — using a smartphone camera, computer vision and deep learning.

## What it does

- **Real-time object detection** — identifies surrounding objects and potential obstacles through the camera
- **Obstacle awareness** — audio alerts about nearby obstacles for safer movement
- **Text recognition (OCR)** — reads visible text from the surroundings
- **Audio feedback (TTS)** — converts detections and recognized text into spoken audio
- **Priority-based alerts** — important information first, no unnecessary noise
- **Emergency assistance** — alerts a designated contact when needed

## Tech stack

- **Python** — AI & computer vision pipeline
- **YOLO** — lightweight real-time object detection
- **OpenCV** — image/video processing & camera handling
- **OCR** — text recognition from camera input
- **TTS** — text-to-speech audio feedback
- **Mobile app** — real-time on-device experience
